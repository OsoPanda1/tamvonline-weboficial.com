# TAMV Online Network — Sitio institucional

Sitio institucional inicial para documentar la identidad pública, las líneas de investigación y desarrollo, la trayectoria, las fuentes primarias y los principios de gobernanza de TAMV Online Network.

## Estado de esta versión

- Sitio estático en HTML, CSS y JavaScript; no requiere instalación de dependencias.
- Diseño adaptable a móvil y escritorio, navegación por secciones, enlaces externos con protección `noopener noreferrer`, preferencia de movimiento reducido y alternancia inicial español/inglés.
- Preparado para despliegue estático en Vercel.
- La página distingue explícitamente la visión de los componentes implementados y evita presentar afirmaciones no verificadas como certificaciones o resultados científicos.

## Despliegue

1. Importar este repositorio en Vercel.
2. Framework preset: **Other**.
3. Build command: dejar vacío.
4. Output directory: `.`.
5. Deploy. Para dominios personalizados, configurar DNS desde el panel del proveedor y comprobar HTTPS.

También puede servirse localmente con cualquier servidor HTTP estático, por ejemplo `npx serve .`.

## Objetivo institucional y preparación para ROR

La web ayuda a establecer una presencia pública consistente, pero **no garantiza un identificador ROR**. ROR registra organizaciones de investigación y financiación, no perfiles individuales. Su orientación oficial señala que las organizaciones unipersonales quedan fuera de alcance y recomienda aportar múltiples publicaciones o conjuntos de datos que citen a la entidad como afiliación, financiadora o editora, junto con evidencia de participación de varias personas.

Antes de solicitar un registro:
1. Buscar si la entidad ya existe en https://ror.org/search.
2. Confirmar que TAMV funciona como entidad colectiva, estable e independiente, no solo como proyecto o marca de una persona.
3. Normalizar un nombre oficial y sus variantes, dirección institucional pública, sitio web y canales de contacto.
4. Reunir varias salidas de investigación verificables (DOI/URL), idealmente publicadas en canales diferentes, que reconozcan explícitamente a la organización y a más de una persona vinculada.
5. Asegurar que las afiliaciones en ORCID, Crossref, DataCite, Zenodo u otros registros coincidan con el nombre institucional usado en las publicaciones.
6. Enviar la solicitud solo cuando la evidencia satisfaga los criterios de inclusión vigentes. La decisión corresponde a los curadores de ROR.

Guía oficial: https://ror.org/blog/2026-06-24-three-tips-for-requesting-ror-id/

## Principios editoriales

- Separar testimonios, visión institucional, prototipos, despliegues operativos y resultados evaluados.
- No declarar acreditaciones, reconocimientos, métricas de usuarios, impacto, alianzas, financiación o validación por pares sin evidencia primaria.
- Mantener un catálogo de producción con título, autores, fecha, tipo de recurso, versión, DOI/URL, licencia y estado de revisión.
- Añadir una política de privacidad, accesibilidad, correcciones, contribuciones y contacto institucional antes de escalar la difusión.
